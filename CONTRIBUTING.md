# Contributing to MedicalBot (Hacktoberfest 2025 Edition)

Thank you for your interest in contributing to MedicalBot! We’re excited to welcome new contributors for Hacktoberfest 2025. Whether this is your first open source contribution or you’re a returning participant, your work is appreciated.

## Hacktoberfest Participation

To have your pull requests count towards Hacktoberfest:
- Register at [hacktoberfest.com](https://hacktoberfest.com/) with your GitHub account.
- Submit pull requests (PRs) to this repository between October 1–31, 2025.
- PRs should be meaningful (not spam) and follow the guidelines below.

Note: Only accepted PRs (merged, approved, or labeled with `hacktoberfest-accepted`) will count towards your Hacktoberfest total.

---

## How to Contribute

1. Fork this repository.
2. Clone your fork to your local machine.
3. Create a new branch for your feature or bugfix:
   ```
   git checkout -b my-feature-branch
   ```
4. Make your changes (new features, bug fixes, documentation improvements, etc.).
5. Test your code if applicable.
6. Commit your changes with a clear message.
7. Push to your fork and open a pull request against this repository.
8. Fill out the PR template, describing your changes.

---

## What Can You Work On?

- Fixing open issues ([see issues](https://github.com/SjxSubham/MedicalBot/issues))
- Improving documentation and comments
- Adding new features or commands
- Bug fixes and code cleanup
- Writing or improving tests
- UI improvements or accessibility enhancements

Look for issues labeled `hacktoberfest`, `good first issue`, or `help wanted`.

---

## Contribution Guidelines

- Follow the project’s code style and naming conventions.
- Write clear and concise commit messages.
- Keep pull requests focused—one feature or fix per PR.
- Be respectful and constructive in code reviews and discussions.
